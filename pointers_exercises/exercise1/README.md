## Exercício 1. Seja o seguinte trecho de programa:
int i = 3, j = 5;
int *p, *q;
p = &i;
q = &j;
# Qual é o valor das seguintes expressões?
a) *p 
b) *p - *q
c) **&p
d) 3 - *p / (*q) + 7

## Respostas:
a) 3;
b) -2;
c) Pega o valor de i;
d) 3 - 3/5 + 7 => 12/5 + 7 => 47/5 como fração ou 9,4 como decimal.
